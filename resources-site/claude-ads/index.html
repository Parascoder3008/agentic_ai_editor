FREE SETUP GUIDE

Meta Ads audit, minuton mein, free Claude plugin se

Claude Ads is a free, open-source plugin for Claude Code (33 skills, 25 AI agents). Yeh guide aapko zero se pehle audit tak le jayegi: install karo, ad data connect karo, aur bolo "is hafte ke mere ads audit karo".

Setup start karo ↓ 📲 Join WhatsApp Channel

Shuru karne se pehle, yeh chahiye

1

Claude paid plan: Pro, Max, Team ya Enterprise (ya Console/API account). Free claude.ai plan mein Claude Code nahi chalta.

2

Computer: Windows 10+, macOS 13+, ya Linux. 4 GB+ RAM, internet.

3

Meta Ads Manager access: jis ad account ka audit karna hai, usmein aapka access ho.

STEP 1

Claude Code install karo

Terminal kholo (Windows: PowerShell, Mac: Terminal) aur apne system ki command paste karo.

irm https://claude.ai/install.ps1 | iex
curl -fsSL https://claude.ai/install.sh | bash

Terminal nahi chahiye? Claude Desktop app download karo: claude.com/download, aur usmein Code tab kholo.

Install ke baad naya terminal window kholo aur check karo:

claude --version

Version number dikhe to install ho gaya. "claude is not recognized" aaye to terminal band karke dobara kholo.

STEP 2

Login karo

Ek project folder banao (jaise meta-audit), us folder mein terminal kholo aur Claude Code start karo. Browser khulega, apne Claude account se login karo.

claude
STEP 3

Claude Ads plugin add karo

Claude Code ke andar yeh do commands ek-ek karke chalao:

/plugin marketplace add agricidaniel/claude-ads
/plugin install claude-ads@ai-marketing-hub-claude-ads

Commands na dikhe to Claude Code band karke dobara claude chalao. Pehle purana version add kiya tha? Neeche Troubleshooting dekho.

STEP 4

Apna Meta ads data do (read-only)

Plugin aapke exports ya read-only account access se audit karta hai. Sabse aasaan tareeka:

Meta Ads Manager kholo → last 30 days select karo → Campaigns, Ad sets aur Ads ki report Export (CSV) karo. Spend, impressions, clicks, CTR, CPM, results aur cost per result columns rakho. File ko apne meta-audit folder mein save karo.

Agar aapke Claude account ke Settings → Connectors mein Meta Ads connector available hai, use connect karo. Yeh read-only data deta hai, export ki zaroorat nahi.

Access tokens ya passwords kabhi chat mein paste mat karo. Plugin by default read-only hai.

STEP 5

Pehla audit chalao 🚀

Pehle ek baar setup (account, KPI aur guardrails profile), phir Meta audit:

/claude-ads:ads setup
/claude-ads:ads audit meta

Ya seedha Hinglish mein bolo: "is hafte ke mere Meta ads audit karo". Aapko milega: kaunsa ad kaam kar raha hai, kaunsa paisa jala raha hai, tracking gaps, creative fatigue aur next steps.

BONUS

Naye ad creatives banao

Image generation provider (jaise Higgsfield MCP) Claude Code mein connect karo, phir:

/claude-ads:ads create

Safety: account mein koi change aapke approval ke bina nahi hota. /claude-ads:ads launch --draft sirf draft plan banata hai.

Commands cheat sheet

/claude-ads:ads setupAccount, KPI, privacy aur guardrail profile
/claude-ads:ads audit metaMeta Ads ka evidence-backed audit
/claude-ads:ads planCampaign, budget aur measurement plan
/claude-ads:ads createAd copy, image aur video assets
/claude-ads:ads monitorPacing, delivery, tracking aur fatigue check
/claude-ads:ads optimize --draftOptimization changes ka draft (apply nahi karta)
/claude-ads:ads reportReport render karta hai

Troubleshooting

"claude is not recognized / command not found"

Install ke baad naya terminal kholo. Phir bhi na chale to official guide: Troubleshoot installation.

Login nahi ho raha / "no access"

Claude Code ke liye Pro, Max, Team, Enterprise ya Console account chahiye. Free plan pe nahi chalta.

Plugin install error (pehle purana version add kiya tha)

Purana alias hata ke dobara add karo:

/plugin marketplace remove agricidaniel-claude-ads
/plugin marketplace add agricidaniel/claude-ads
/plugin install claude-ads@ai-marketing-hub-claude-ads
Audit mein data kam aa raha hai

Export mein campaign, ad set aur ad, teeno levels rakho, aur results/cost per result columns zaroor include karo. Missing data ko plugin "unknown" mark karta hai, guess nahi karta.
