STEP 1

Kapso account + WhatsApp number

  1. app.kapso.ai pe sign up karo (free plan).
  2. Connected numbers → Connect new number kholo aur ek option chuno:
Instant setup: Kapso ka pre-verified number. Testing ke liye sabse fast, SMS verification nahi chahiye.
WhatsApp Business App: aapka current business number, jo WhatsApp Business app mein chal raha hai. App bhi chalta rahega, agent bhi. QR code se pair hota hai.
Bring your own SIM: ek naya dedicated number sirf agent ke liye.

Phir Meta ka signup khulta hai: Facebook se login karo, Business portfolio aur WhatsApp Business account chuno (ya naya banao), Confirm, phir Finish. Kapso mein number connected dikhega.

Meta ke rules number connect hone ke baad bhi lagte hain: business info (naam, address, website) complete rakho. Display name review, business verification aur template approval Meta karta hai.

Sirf test karna hai? WhatsApp → Sandbox → Add Test Number se apne phone pe safely test karo, bina asli number connect kiye.

STEP 2

Ek command: WhatsApp skills Claude Code mein

Claude Code wale computer pe terminal kholo aur yeh chalao:

npx skills add gokapso/agent-skills

Isse 4 skills aati hain: integrate-whatsapp (number, webhooks, messages, templates), automate-whatsapp (workflows, agents, database), observe-whatsapp (logs, debugging) aur integrate-whatsapp-calling (WhatsApp calls).

Phir Kapso dashboard (app.kapso.ai) se API key banao aur set karo:

MAC / LINUX
export KAPSO_API_BASE_URL="https://api.kapso.ai" export KAPSO_API_KEY="your-api-key"
WINDOWS (POWERSHELL)
$env:KAPSO_API_BASE_URL="https://api.kapso.ai" $env:KAPSO_API_KEY="your-api-key"

API key password jaisi hai: kisi ko share mat karo, screenshot mein mat dikhao, aur code ke saath GitHub pe mat daalo.

STEP 3

Claude ko bolo: booking agent banao

Claude Code mein yeh prompt paste karo. Brackets wali cheezein apne business se bhar do:

Kapso ki WhatsApp skills use karke mere business ke liye ek WhatsApp booking agent banao. Business: [naam], [city] Services aur price: [service 1 - ₹___], [service 2 - ₹___] Timings: [Mon-Sat, 10am-8pm] Agent ko yeh karna hai: 1. Customer slot pooche to agle 7 din ke 3 free slots buttons mein dikhao. 2. Customer slot chune to booking confirm karo (naam, service, time), bookings ek database table mein save karo, aur confirmation message bhejo. 3. Prices aur FAQs sirf upar diye data se batao. Jo nahi pata, bolo "main team se confirm karke batata hoon" aur mujhe notify karo. 4. Hinglish mein, short aur polite replies. 5. Kisi ko pehle message mat bhejo jab tak usne opt-in na kiya ho. 24 ghante ki chuppi ke baad sirf approved template bhejo. Pehle plan dikhao, phir build karo, aur Kapso Sandbox pe test karke mujhe batao.

Claude code likhta hai, aap review karte ho. Agent aapke connected number pe 24 ghante chalta hai.

⚠️ WhatsApp ke rules (zaroori)

  • Permission pehle: sirf unhi customers ko message karo jinhone opt-in kiya hai.
  • 24-ghante ka window: customer ke last message ke 24 ghante baad sirf Meta-approved template bhej sakte ho.
  • Billing: Kapso free plan mein 2,000 messages/mahina, aur bheje + aaye dono gine jaate hain. Meta ke WhatsApp charges Kapso plan se alag hain.
  • Limits badal sakte hain: setup se pehle kapso.com/pricing check karo.
