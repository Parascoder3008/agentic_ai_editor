LEVEL 1

Chat: behtar prompt, behtar jawab

Level 1 bura nahi hai, bas adhoora hai. Ek line ka sawaal generic jawab deta hai. Har prompt mein yeh 4 cheezein do: kaun ho, kya context hai, kya chahiye, kis format mein.

Tum meri boutique ke social media manager ho. Context: Lajpat Nagar, Delhi mein women's ethnic wear store. Customers 25-45 age, budget ₹1,500-₹5,000. Task: Diwali silk saree collection ke liye 3 Instagram captions likho. Format: Hinglish, har caption 2 lines, ek call to action, 3 hashtags.

Problem: har nayi chat mein yeh context dobara likhna padta hai. Isi ka solution Level 2 hai.

LEVEL 2

Projects: business context ek baar daalo

  1. Claude mein left side se Projects kholo (ya claude.ai/projects) → + New Project.
  2. Project knowledge mein + dabake apni files daalo: price list, FAQs, services, brand tone (PDF, Doc, text).
  3. Set project instructions pe click karke neeche wale instructions paste karo → Save instructions.
Tum [Business Name] ke assistant ho. Hamesha project files mein di gayi prices, FAQs aur policies use karo; jo files mein nahi hai, use guess mat karo, mujhse poocho. Tone: friendly, simple Hinglish, short sentences. Har customer reply mein: seedha jawab, ek helpful detail, aur ek clear next step (call, visit ya WhatsApp).

LEVEL 3

Connectors: Gmail, Calendar, Drive jodo

  1. Claude mein Customize → Connectors kholo aur Gmail, Google Calendar, Google Drive apne Google account se connect karo.
  2. Kisi bhi chat mein + → Connectors se inhe on/off kar sakte ho.
  3. Team/Enterprise plan pe pehle admin ko Organization settings → Connectors mein enable karna hota hai.

Phir aise bolo:

Gmail mein pichhle 2 din ki customer enquiries dhoondo. Har ek ka reply draft karo (prices project files se), aur jinhone call maanga hai unke liye Thursday shaam 4-6 ke beech calendar slot suggest karo. Kuch bhi bhejne se pehle mujhe dikhao.

By default Claude har action (send, reply, share) se pehle aapka approval maangta hai. Attachments ka content Claude nahi padh sakta, sirf unki details.

LEVEL 4

Scheduled tasks: roz apne aap

Yahan Claude chatbot nahi, aapka assistant ban jaata hai. Ek baar bolo, aur kaam roz time pe hota hai.

  1. Kisi bhi chat mein task aur timing describe karo (neeche wala prompt), Claude ke sawaalon ka jawab do.
  2. Proposed name, schedule aur instructions review karo → Schedule.
  3. Ya Scheduled page → New task → frequency choose karo (hourly, daily, weekdays, weekly).
Har subah 9 baje: Gmail se kal ki saari customer enquiries padho aur mujhe ek summary bhejo. Har enquiry ke liye: naam, kya chahiye, urgency (high/medium/low), aur ek suggested reply. Sabse urgent wali sabse upar.

Scheduled tasks remotely chalte hain, laptop band ho tab bhi. Sirf jo task aapke computer ki local files use karta hai, woh tabhi chalta hai jab computer on ho.
